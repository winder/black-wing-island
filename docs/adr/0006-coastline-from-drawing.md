# 6. Coastline comes from Caitlin's drawing

Date: 2026-10-03
Status: Accepted. Drawing received: `assets/island-drawing.png`

## Decision
Caitlin draws the dragon-shaped outline of the Island. The image becomes a mask that defines land vs. ocean. Procedural terrain fills it in using a fixed seed, so the island is the same every game. Biomes are placed by the dragon's anatomy (mountains along the spine, etc.).

## Constraint
No building work starts until Caitlin provides the picture.
